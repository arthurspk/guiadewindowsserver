## :dart: O guia para alavancar a sua carreira

> Windows Server continua sendo a espinha dorsal de rede corporativa da maioria das empresas brasileiras: Active Directory, DNS, DHCP, Group Policy, Hyper-V e File/Print Server aparecem em praticamente toda vaga de suporte, infraestrutura e administração de sistemas. Este guia reúne roadmap, documentação oficial, cursos gratuitos e pagos, livros, canais, ferramentas, projetos práticos, certificações Microsoft e um capítulo dedicado a usar IA na prática com Windows Server — tudo verificado e organizado para quem está subindo o primeiro Domain Controller ou quer aprofundar em Group Policy, hardening de Active Directory e administração híbrida com o Entra ID.

## 🤖 IA na prática

Administrar Windows Server envolve muito comando de linha, script PowerShell e leitura de logs densos — exatamente o tipo de tarefa onde um assistente de IA economiza tempo, desde que você confira o resultado antes de rodar em produção.

**Para aprender**
- Cole um erro de PowerShell ou de Event Viewer (ex.: falha ao promover um servidor a Domain Controller) e peça: *"explique a causa provável e como corrigir, passo a passo"*.
- Peça para explicar, linha por linha, um script de administração de Active Directory que você não escreveu — scripts de GPO e AD costumam ser densos e cheios de parâmetros pouco intuitivos.
- Peça exercícios práticos: *"monte um cenário de troubleshooting de replicação do Active Directory e me guie sem dar a resposta direto"* — você tenta, a IA revisa.
- Use a IA para gerar rascunhos de scripts PowerShell (criação em massa de usuários, relatórios de GPO) e depois valide cada linha contra a [documentação oficial dos módulos](https://learn.microsoft.com/en-us/powershell/module/activedirectory/).

**Para trabalhar**
- Ferramentas como o [GitHub Copilot](https://github.com/features/copilot) e o [Claude Code](https://code.claude.com/docs/en/overview) ajudam a escrever e revisar scripts PowerShell de automação de AD, DNS e GPO a partir de uma descrição em linguagem natural.
- O [Microsoft Security Copilot](https://learn.microsoft.com/en-us/copilot/security/microsoft-security-copilot) é o assistente de IA oficial da Microsoft para investigar incidentes de segurança, incluindo comprometimento de Active Directory, correlacionando sinais de várias ferramentas.
- Depois de aceitar qualquer script de IA para o Active Directory, rode-o primeiro num ambiente de laboratório (como o [GOAD](https://github.com/Orange-Cyberdefense/GOAD)) antes de aplicar em produção.

**Limites e boas práticas**
- IA **inventa parâmetros e cmdlets** do PowerShell com frequência, principalmente para módulos menos comuns. Confira sempre na [referência oficial dos módulos](https://learn.microsoft.com/en-us/powershell/module/).
- Nunca cole hashes de senha, tickets Kerberos ou despejos de banco de dados do Active Directory (NTDS.dit) em um chat de IA — esse é justamente o tipo de dado que ferramentas de comprometimento de domínio procuram.
- Desconfie de scripts sugeridos que desabilitem políticas de senha, concedam privilégios de Domain Admin "só para testar" ou desativem o firewall — peça sempre o porquê antes de rodar.
- Ao usar um assistente de IA para gerar GPOs, aplique primeiro numa Unidade Organizacional (OU) de teste, nunca direto na raiz do domínio.

## 🎓 Certificações

- [AZ-800: Administering Windows Server Hybrid Core Infrastructure (oficial)](https://learn.microsoft.com/en-us/credentials/certifications/exams/az-800/) — Exame oficial da Microsoft sobre administração híbrida de identidade, redes e armazenamento do Windows Server — exame pago.
- [AZ-801: Configuring Windows Server Hybrid Advanced Services (oficial)](https://learn.microsoft.com/en-us/credentials/certifications/exams/az-801/) — Exame oficial complementar ao AZ-800, com foco em segurança, migração e recuperação de desastres híbrida — exame pago.
- [Windows Server Hybrid Administrator Associate (oficial)](https://learn.microsoft.com/en-us/credentials/certifications/windows-server-hybrid-administrator/) — Certificação oficial da Microsoft que exige os exames AZ-800 e AZ-801, o padrão de mercado para administradores de Windows Server.
- [MS-102: Microsoft 365 Administrator (oficial)](https://learn.microsoft.com/en-us/credentials/certifications/exams/ms-102/) — Exame oficial que cobre identidade híbrida com Microsoft Entra ID, complementar ao trabalho com Active Directory local — exame pago.
- [SC-300: Identity and Access Administrator (oficial)](https://learn.microsoft.com/en-us/credentials/certifications/identity-and-access-administrator/) — Certificação oficial de gestão de identidade e acesso, cada vez mais associada a ambientes híbridos com Active Directory — exame pago.
- [AZ-104: Azure Administrator Associate (oficial)](https://learn.microsoft.com/en-us/credentials/certifications/azure-administrator/) — Certificação oficial para quem administra recursos do Azure, caminho comum para quem migra de Windows Server local para nuvem — exame pago.
- [CompTIA Server+](https://www.comptia.org/en-us/certifications/server/) — Certificação vendor-neutral sobre administração de servidores, boa base antes de partir para certificações específicas da Microsoft — exame pago.
